關於成語學習

關於本應用

這是一個成語學習應用程式，採用溫暖的"餃子風格"設計，旨在讓學習成語變得更加有趣和親切。

應用程式將每個成語的詳細資訊分離為獨立的JSON檔案，便於管理和擴展。

學習內容

本應用包含多個成語類別：

常用成語

日常生活中經常使用的成語

成語故事

具有豐富歷史背景和故事的成語

動物成語

包含動物名稱的成語

數字成語

包含數字的成語

技術實現

本應用使用以下技術：

1. HTML5, CSS3, JavaScript (ES6+)

2. Font Awesome 圖標庫

3. 響應式網頁設計

4. JSON 數據結構

5. Fetch API 加載數據
